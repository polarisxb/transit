接入

选一把密钥、选你的工具，复制配置粘进去就能用。配置里已经把密钥和地址填好了。

使用密钥
写入 ~/.claude/settings.json（Windows：%USERPROFILE%\.claude\settings.json）
{ "env": { "ANTHROPIC_BASE_URL": "https://api.transit.local", "ANTHROPIC_AUTH_TOKEN": "sk-tr9k2m8fd0a1b7c3e5f9g2h4j6k8l0m2n4p6q8r0s2t4u6v8w0x2y4z6a8f2a", "API_TIMEOUT_MS": "3000000", "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1" } }
  • API_TIMEOUT_MS 调大是为了长任务不掉线，保留这一行。
  • 保存后重新打开 Claude Code，运行 /status 能看到 Base URL 已切换。
  • 模型用 claude-opus-4.7 / claude-sonnet-4.6，与官方一致。
写入 ~/.codex/config.toml
model = "gpt-5.5" model_provider = "transit" [model_providers.transit] name = "transit" base_url = "https://api.transit.local/v1" env_key = "TRANSIT_API_KEY" wire_api = "responses"
再设置环境变量
# macOS / Linux（写进 ~/.zshrc） export TRANSIT_API_KEY="sk-tr2c…41be" # Windows PowerShell setx TRANSIT_API_KEY "sk-tr2c…41be"
